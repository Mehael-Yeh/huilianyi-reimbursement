## 关键只读技巧
- 在列表页**点击"单号"单元格**会打开该单据的打印 PDF（cloudhelios OSS 签名 URL，1 小时内有效）。
- 用 `browser_console` 读 `location.href` 拿到 PDF 签名 URL，再 `web_extract` 该 URL 得全文文本——是解析表单完整结构的最快方法。
- PDF 阅读器以 iframe 覆盖全页；读完 `browser_navigate` 回列表 URL 关闭。

## 报销单三种类型
对公付款单 / 差旅报销单 / 个人报销单（见"新建报销单"下拉）。
差旅报销单 = 出差（过路费、酒店、出差补贴、其他交通），**必关联差旅申请单**。
个人报销单 = 非差旅（里程补贴、其他招待费用），**不关联申请单**，事由如"客户拜访"。

费用分三类：
- **贴票费用**：有发票并贴在费用明细下
- **无票费用**：无发票（如出差补贴），只列客户名称
- **免贴票费用**：发票信息与费用项分列

**发票抬头必须为「示例公司甲」**（用户集团内另一公司，≠开户的浙江佑谦）。

## 差旅申请单表单字段（* = 必填）
- 费用承担公司 *（默认示例公司乙）
- 费用承担部门 *（默认树脂销售）
- 代理人 *（≠参与人）
- 开始日期-结束日期 *（日期区间，联动显示天数）
- 是否总务订机票 *
- 目的地
- 单程/往返 *
- 研发项目
- 交通工具 *（文本）
- 参与人 *（一起订票填多人需一起报销；分开报销填自己）
- 事由 *
- 按钮：保存并添加明细 / 返回；有"检查重复申请"

## 审批流（固定）
示例用户提交 → 审批人乙(销售树脂经理) → 审批人丙(总经理/总监) → 审批人丁(收单/审核) → 审批人戊(成本会计) → 审批人己(经理) → 审批人庚(出纳)付款。
