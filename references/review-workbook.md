# Excel 核对表

费用保存并回读后必须生成 `.xlsx` 文件供用户确认，不以终端 JSON 代替。

## 工作表

### 汇总

- 申请单号、差旅报销单号、个人报销单号。
- 差旅预算、差旅实际、个人报销和全部报销合计。
- 待确认、保存失败和重复票据数量。
- 按费用类别汇总预算、实际、差额和票据数量。

汇总金额使用公式引用明细表，不能硬编码。

### 票据明细

至少包含：

| 字段 | 说明 |
|---|---|
| 文件名、格式 | 原始材料定位 |
| 材料类型 | 发票或附件 |
| 发票号码 | 文本提取结果 |
| 自动建议分类、用户确认分类 | 保留自动判断和最终决定 |
| 归属单据 | 差旅报销、个人报销或待确认 |
| 识别金额、最终报销金额 | 数值格式，附件金额不计入 |
| 金额来源、分类依据 | 可审计信息 |
| 置信度、是否需核对 | 低置信度醒目标记 |
| 汇联易费用编号、保存状态 | 回读结果 |
| 备注 | 用户补充信息 |

### 类别核对

按类别汇总申请金额、报销金额、差额、票据数量和未关联申请的费用数量。

## 格式与验收

- 冻结表头、启用筛选，金额使用两位小数。
- 待确认和失败状态使用条件格式突出显示。
- 用户可编辑的“用户确认分类、最终报销金额、备注”应与汇总公式联动。
- 扫描公式错误，检查汇总金额与汇联易回读总额一致。
- 重新打开生成文件，检查工作表、公式、数字格式和文本型编号；执行环境支持渲染时，再渲染全部工作表检查标题、列宽、换行和金额是否可见。
- 文件名不包含账号、密码或内部 OID；必要时只保留业务单号。
