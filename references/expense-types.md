# 汇联易 可用费用类别（发票可落类别）

从 `POST /api/expense/type/byUser` 提取，body `{"companyOID":"OID_1","formOID":<表单OID>,"roleType":"TENANT"}`。
字段：`name`(类别)、`expenseTypeId`(v5/invoices 请求体用的数字 id)、`expenseTypeOID`、`code`、`classificationCode`。
表单OID：差旅报销单=`OID_2`，个人报销单=`OID_3`。
（抽屉注：其他招待费用 id=`1704675864861536258` 已实测用于 v5/invoices 建行成功；餐费同理可在个人报销单用之。）
