## 分类映射（CATEGORY_CONFIG）
| 类别 | 归属组 | 判定密钥词（haystack=文本+文件名 compact） |
|---|---|---|
| 过路费 | 1.差旅报销 | 收费公路/通行费/道路通行/公路通行/高速公路通行/过路费/过桥费/过闸费；通行费电子票据标准文件名 `序号_税号_哈希.pdf` |
| 酒店 | 1.差旅报销 | 住宿服务/住宿费/酒店服务/宾馆住宿 |
| 停车费 | 1.差旅报销 | 停车/车辆停放 |
| 打车费 | 1.差旅报销 | 客运服务费/网约车/出租车/打车/代驾/旅客运输服务/出行服务 |
| 其他交通 | 1.差旅报销 | 铁路电子客票/航空运输电子客票/机票/飞机票/火车票/高铁票 |
| 餐费 | 2.个人报销 | 餐饮/餐费（金额≤40元） |
| 礼品费 | 2.个人报销 | 餐饮且金额>40元；礼品/烟草制品/食品/焙烤/饮料/酒/茶叶/水果/超市/便利店/百货/福利 |
| 里程补贴 | 2.个人报销 | 成品油/*汽油*/*柴油*/车用汽油/加油站/油票/燃油 |

## 关键规则
- **"生产生活服务"是上位词**，不得仅凭它归类，必须继续识别具体项目：通行费→过路费、停车→停车费、餐饮→按40元规则。
- **餐费 >40元 自动礼品费；40元及以下仍餐费。**
- 打车行程单/通行费汇总单（`_行程单`/`_汇总单`/AMAPITINERARY）→ 归档对应类别但**不计入金额**。
- 重复文件或相同发票号码只计一次，重复件进"待核对"。
- 未命中明确分类 → 暂放礼品费 + needs_review=true（需人工核对）。
- 发票抬头应为 **示例公司甲**。

## 金额提取
- 优先取 PDF 内货币最大值（¥ / 价税合计 / （小写）等模式）。
- 文件名金额 `日期_金额_公司.pdf` 兜底；不一致时取文件名并标注。
- 文本层为空/缺金额/缺日期/需核对 → 本地 RapidOCR 兜底（NAS 未装 OCR，仅文本层）。
