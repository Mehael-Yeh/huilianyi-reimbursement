# 票据分类与金额提取

## 处理顺序

1. 校验扩展名，仅接收 PDF、OFD、ZIP、XML。
2. 提取文本并标准化全角字符、大小写和空白。
3. 判断材料是发票还是行程单、汇总单等附件。
4. 提取发票号码与含税总额，记录来源和候选值。
5. 使用项目名称、服务名称、销售方名称和文件名进行分类。
6. 对重复、冲突和低置信度条目标记人工核对。

不能只凭文件名、上位服务名称或全文最大数字决定分类和金额。

## 格式化文本提取

| 格式 | 提取方法 | 失败处理 |
|---|---|---|
| PDF | 逐页读取文本层并保持页序 | 文本为空或乱码时标记“需 OCR”，不上传图片替代 |
| OFD | 按 ZIP 容器读取 XML 文本节点，合并发票结构字段 | XML 损坏、加密或关键字段缺失时标记人工核对 |
| XML | 解析元素文本与本地标签名，优先识别结构化金额字段 | 解析失败时不使用正则猜测金额 |
| ZIP | 递归读取内部 PDF/OFD/XML；限制解压后总大小 | 加密包、超限包或不支持文件单独列入待确认 |

ZIP 中的每张独立发票必须形成独立记录；不能把包内多个金额合并成一张发票。

## 金额提取

金额候选按以下优先级选择：

1. `价税合计（小写）`、`TotalTaxIncludedAmount`、`TaxInclusiveTotalAmount`、`AmountIncludingTax` 等结构化含税总额字段。
2. `价税合计`、`票价合计`。
3. `实付金额`、`支付金额`、`应付金额`。
4. `合计金额`、`金额合计`、`总金额`。
5. 带 `¥` 或 `￥` 的金额，仅当邻近文本不含“税额、单价、不含税、优惠、折扣”。
6. 文件名只有在数字前明确出现“金额、价税合计、合计”时才可作为低置信度兜底。

规则：

- 金额使用两位小数，去除千分位；负数、零和异常大值不自动采用。
- 不使用全文最大值策略，因为税号、发票号码、日期、单价和税额可能更大。
- 同优先级出现不同金额时不自动选择，标记金额冲突。
- 文本金额与结构化金额不一致时优先结构化字段，同时保留全部候选值供核对。
- 汇总单、行程单、通行记录等附件金额不计入报销合计。
- 同一发票号码只计一次；号码缺失时使用文件哈希和关键字段组合辅助查重。

## 分类关键词

项目名称或服务名称的命中权重高于销售方名称；销售方名称只作为辅助证据。命中强证据可直接建议分类，仅命中辅助证据或多个类别同分时必须人工核对。

| 建议分类 | 归属 | 强证据（优先查项目名称） | 辅助证据 | 排除与复核 |
|---|---|---|---|---|
| 过路费 | 差旅报销 | 收费公路通行费、道路通行服务、高速公路通行费、ETC通行费、过路费、过桥费、过闸费 | 通行费、收费公路、高速通行 | “汇总单、通行记录”且无发票号码时只作附件 |
| 酒店 | 差旅报销 | 住宿服务、住宿费、客房费、房费、宾馆住宿、酒店服务 | 酒店、宾馆、旅馆、住宿 | 仅销售方含“酒店”但项目为餐饮时按餐饮判断 |
| 停车费 | 差旅报销 | 停车服务、车辆停放服务、停车费、停车场服务 | 停车、车辆停放 | 车辆维修、洗车不属于停车费 |
| 打车费 | 差旅报销 | 出租车客运服务、出租汽车、网约车、打车服务、代驾服务、平台出行名称 | 出租车、网约、打车、代驾、出行服务 | 铁路和航空旅客运输不归入打车费 |
| 其他交通 | 差旅报销 | 铁路电子客票、航空运输电子客票、航空运输客票、火车票、高铁票、动车票、机票、客运票 | 铁路、航空、高铁、动车、旅客运输 | 航空行程单若不是发票，按附件处理 |
| 餐费 | 个人报销 | 餐饮服务、餐饮费、餐费 | 饭店、餐馆、酒楼、小吃 | 按当前业务规则，金额超过 40 元转为礼品费 |
| 礼品费 | 个人报销 | 礼品、烟草制品、茶叶、酒类、水果、焙烤食品、预包装食品、超市、便利店、百货 | 食品、饮料、酒、茶、烟、水果、商贸 | 泛化“商贸、食品”单独命中时需要核对 |
| 里程补贴 | 个人报销或按历史 | 项目名称含加油、油卡、油卡充值、成品油、车用汽油、车用柴油、汽油、柴油、燃油费 | 销售方含加油站、石油、石化，或文本含油品、加油 | 油卡和油票不能自动证明费用类型名称，必须参考近期历史政策 |

## 冲突和置信度

- “生产生活服务、现代服务、其他服务”等上位词不参与最终分类。
- 强证据命中一个类别且无冲突：高置信度。
- 只有辅助证据、多个类别得分相同、油卡/油票政策不明：低置信度并人工核对。
- 完全未命中时分类为“待确认”，不得默认归入礼品费或其他费用。
- 用户确认后的分类优先于自动建议，但需在 Excel 核对表中保留原建议和确认结果。
