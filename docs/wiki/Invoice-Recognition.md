# 票据识别与分类

## 支持格式

| 格式 | 处理方式 |
|---|---|
| PDF | 提取文本层 |
| OFD | 解包并解析 XML 文本 |
| XML | 读取结构化元素和标签 |
| ZIP | 递归处理内部 PDF、OFD、XML；加密时先向用户索取密码；同一发票的多格式版本只计一次 |

图片格式票据不上传。文本缺失时标记需要 OCR 或人工确认。

## 金额

优先级依次为含税合计、票价合计、实付/应付、其他明确合计。带货币符号的数字仅作辅助候选；税额、单价、不含税金额、优惠和折扣不能作为报销总额。

文件名中的数字只有在前面明确写有“金额、价税合计、合计”时才可作低置信度兜底。PDF 文本层缺少金额时，保存前使用汇联易 OCR/查验返回的含税金额；显式金额与查验金额不一致时停止。不同高优先级候选不一致时必须人工确认。

## 分类

项目名称和服务名称优先，销售方名称与文件名辅助。主要类别包括过路费、酒店、停车费、打车费、其他交通、餐费、礼品费和里程补贴。

里程补贴应识别项目名称中的“加油、油卡、油卡充值、汽油、柴油、燃油”等信息；销售方名称中的“加油站、石油、石化”只作辅助证据。最终费用类型仍需依据近期历史或用户确认。

未知类别必须标记“待确认”，不能默认归入礼品费。

完整关键词、冲突和附件规则见 [票据分类与金额提取](../../references/invoice-classification.md)。
